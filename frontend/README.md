# Krishi Saathi Frontend

React + Vite frontend connected to the Python FastAPI backend.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:5173`.

Set `VITE_API_BASE_URL=http://localhost:8000` if the backend is hosted somewhere else.

The Premium tab uses the browser x402 AVM client and Pera/Defly wallet adapters on Algorand Testnet.
